🎧 LouDuck

基于 ITU-R BS.1770-5 标准的沉浸式音频响度测量工具

macOS Windows ADM BWF 开源

✨ 功能特性

📊

响度测量

集成响度、短时响度、瞬时响度、真峰值

🎵

多格式支持

WAV、FLAC、MP3、OGG、ADM BWF

🔊

沉浸式音频

5.1、7.1、5.1.4、7.1.4 声道配置

📄

ADM 解析

自动识别音频定义模型元数据

⬇️ 下载

🍎 macOS

支持 使用 Apple silicon 的 M 系列芯片的 macOS 14 或更高版本

下载 Apple Silicon 版 M1/M2/M3/M4/M5
安装提示：首次运行请右键点击应用 → "打开" → "仍要打开"，以绕过 Gatekeeper。

🖥️ Windows

支持 Windows 10/11 64 位系统

下载 Windows x64 版

📖 使用指南

  1. 下载对应版本的 ZIP 文件并解压
  2. macOS：右键打开应用并允许运行
  3. 导入音频文件（支持单文件或多文件模式）
  4. 选择声道配置（自动检测或手动选择）
  5. 点击"开始测量"获取响度结果
  6. 导出 CSV 报告
